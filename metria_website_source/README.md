# Metria Website

Production website for Metria, a startup building review systems for high-stakes decisions.

## Product Positioning

Metria helps teams review interviews, assessments, and sensitive case material with psychologist-guided protocols, calibrated reviewers, and defensible decision records.

The website deliberately avoids founder biography and school affiliation. The public story is product-first:

- structured review packets
- psychologist-authored protocols
- reviewer calibration
- evidence and counterevidence logs
- decision records for audit

## Local Development

Use Node.js `>=22.13.0`.

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production Build

```bash
npm run build
npm test
```

The production build is generated by `vinext build`.

## Deploying to metria.com

The code cannot create `metria.com` by itself. The domain must be owned or acquired first. After you control the domain, deploy the site to a host and add the domain in that host.

### Option A: Current Sites Hosting

The current hosted site already exists in Sites. To make it load from `metria.com`:

1. Buy or control `metria.com`.
2. Add `metria.com` as a custom domain in Sites.
3. Copy the DNS validation records returned by Sites into the domain registrar DNS panel.
4. Wait for validation and SSL issuance.
5. Add `www.metria.com` too, then redirect one hostname to the other.

### Option B: Vercel

1. Push this repository to GitHub.
2. Import the repository into Vercel.
3. Framework preset: Next.js.
4. Build command: `npm run build`.
5. Add `metria.com` and `www.metria.com` in Vercel project domains.
6. Copy Vercel's DNS records into the registrar DNS panel.

### Option C: Cloudflare Pages

1. Push this repository to GitHub.
2. Create a Cloudflare Pages project from the repository.
3. Build command: `npm run build`.
4. Add `metria.com` and `www.metria.com` as custom domains.
5. Follow Cloudflare's DNS instructions.

## Important Domain Note

If `metria.com` is already owned by someone else, you cannot use it unless you purchase it from the owner or choose a different domain. Alternatives that often preserve brand quality:

- `metria.so`
- `metria.health`
- `metriareview.com`
- `usemetria.com`
- `metriahq.com`
